A short video about an AI coding agent building a tiny browser game — Star Catcher — from one prompt while you watch, posted on X for make.fun's "The agent builds a game from one prompt" bounty. The game itself (catch falling stars, dodge bombs, 3 lives) is in `game/index.html`; the video is `../video.mp4` in the build work dir.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
